# samples/

Drop a few JPEGs or PNGs in here and run:

    python3 run.py --camera folder --folder samples

The folder source replays them one per frame, looping forever. It is the
quickest way to check the detector and the web page against real photographs
before the camera is mounted where you actually want it.

Images are not committed to the repository (see `.gitignore`) — use your own.
